# agentic26 · Navigation

GOSIM Agentic App 2026 参赛开发仓库，主场景为 Navigation，实现方向为**帝王蟹能力层**。

## 产品目标

在限定时间内组合步行、公交、地铁和打车，以最低费用抵达目的地，包含混合路线中的打车计费。通过已授权的跨应用上下文和逐步学习的偏好减少用户表达，只追问影响任务完成的关键缺失信息；学习到的偏好允许用户查看和纠正。日历、消息、机票邮件或设备状态是候选数据源，具体接入尚待确定。

初赛以 OctoScript 应用交付，复用比赛官方宿主，应用模型指定为 MiniMax M3（`MiniMax-M3`）。Agent 通过工具读取背景、查询交通并决定下一步，确定性代码检查候选路线，应用呈现方案和任务结果。模型与交通循环复用现成网络接口；用户另行批准补齐 macOS 实时定位的宿主链路，参赛应用仍以 OctoScript 交付。本项目继续以可被调用的出行能力为重点，自然语言入口与可纠正的目的地、候选方案视图是当前开发入口。

直接服务接入已获用户允许，不再要求所有数据与操作经过手机既有应用。首轮先接任务必需的服务；天气、提醒、手机自动化和运行时动态生成工具不作为前置，避免扩展到完整出行服务平台。

当前路线规划不按演示城市限制起终点，输入是一句“40 分钟内到机场，预算 50，尽量便宜。”系统需要从已授权、有来源的行程、位置和偏好补全机场、币种和出发位置。没有可靠行程时，Agent 查询机场候选并提出可纠正的目的地假设；真实位置不能将模拟机票变成用户的真实行程。真实公共交通任务已完成确认、读回与重启恢复，另有真实混合任务完成确认读回；各版本、条件和剩余边界归[当前任务](tasks/capability-boundary/packet.md)。

演示背景也按实际来源分别提供：日历文件、笔记和设备位置记录。Agent 在运行时关联这些资料，形成带依据的出行约束；不预先把目的地、偏好和起点整理为一个“行程背景文件”。演示数据与真实在线服务结果分别标注。应用已接入一次性设备定位请求，默认使用真实设备位置，模拟位置保留为显式演示模式；系统调用的实际结果与完成证据见任务包。

后续考虑疲劳、最快等目标，比较时间、换乘和可靠性的候选方案。用户确认后建立 Trip，交通条件变化时重新规划、再次确认并核验结果。“最慢”的含义尚未确定；“最晚出发”是候选解释。

## 当前能力

当前应用固定保留自然语言输入和单一查询／终止按钮。MiniMax M3 根据当前任务事实组合内容区的文字、布局、地点选择、路线、地图、条件修改和操作组件；不是执行模型生成的任意代码。组件兑现实际对象与操作，地点预览、切卡、展开和地图加载在本地响应，不为每次点击重新请求模型。Navigation 单独使用中文无衬线字体，宿主与其它应用的文楷主题保持原样。点击卡片只改变查看对象，独立确认按钮才会重新检查并保存 Trip；地图加载失败不影响候选比较。默认展示推荐、最快和最低已知估价的代表候选，完整列表可展开。地图使用高德返回的同源几何；缺段、几何过长或没有几何时明确标为部分概览或端点预览，不补直线或重新计算另一条路线。MiniMax M3 自主选择工具，默认向有权限的宿主请求真实设备位置，并从高德机场候选提出目的地假设；未接通真实机票时明示推断依据与航站楼未知。显式 demo 模式使用独立模拟位置、日历与笔记，保留带引用的机场／航站楼关联。随后查询公共交通与驾车数据，确定性代码检查费用、原始到达期限及实际路线端点；每条候选显示已知费用、耗时、主要路段和全部未通过原因。未取得候选或比较中断时明确说明，不能据此断言现实不可达。

查询后可在本应用搜索、预览并采用目的地，也可通过独立 Maps 的搜索结果选择地点。Maps 返回的 WGS84 坐标经高德转换和城市核实后用于重新规划，不伪造高德 POI 标识；原始截止和预算保留。Maps 取消或关闭后保留原任务结果。当前起点始终为设备位置，不支持手选起点或地图任意落针。

目的地也可在输入框纠正，预算或分钟数可单独修改；这些修改和停止后继续都保留首次收到指令的时间，重新取得位置与交通数据。修改时限会按原始起算时间计算新截止；完整的新分钟数及预算指令才开始新行程。未知价格、不完整或已过期的方案可以查看，不能确认。恢复的 Trip 明示历史状态和模拟来源，不视为当前有效路线。

历史在线基线在官方 stock OctoSense 的 macOS arm64 宿主完成：使用模拟位置，M3 补全深圳宝安机场 T3 国内出发与人民币，选中供应商估价 ¥3、1403 秒的公共交通路线，确认、写入读回及重启恢复通过。另一个模拟位置取得打车接地铁的完整候选 ¥19、2063 秒并确认读回。这些历史记录证明其对应源码与条件，不能代替当前真实定位、自动机场推断的完整任务证据。

2026-10-03 用户确认“0.1 验收通过”。对应源码的后续真实查询六轮约 19 秒：取得广州番禺位置、推断白云机场、查询公交与驾车，共取得 8 条候选；公交约 147–157 分钟、估价 ¥5–13，驾车约 56–60 分钟且费用未知，均超过原始 40 分钟期限。没有读取模拟日历或笔记，航站楼仍未知。这证明一次真实约束负例，不能推论所有现实出行方案均不可行。0.2 将网络派发拆到独立脚本入口，并按本机派发与服务等待区分失败；候选摘要由确定性检查形成，保留历史模拟来源。0.2 实现与验证记录归[交互任务包](tasks/interaction-integration/packet.md)，不能以历史任务替代当前版本验收。

2026-10-04 的 0.2 整合验证使用明确标注的模拟起点与背景、真实 M3／高德和 Maps：从独立 Maps 搜索公开机场并采用后，经坐标转换、城市核实及起点刷新，完成三次公交策略和驾车查询，形成 14 条候选并展示比较负例。实际切卡、同源静态图、拒绝无效确认及 Maps 取消保持原目标和截止均通过；模型输入最大 12,747 字节。本次真实定位先返回权限拒绝，未修改系统授权；Maps 的搜索和往返可用，但其底图当时为空白。该记录不等于真实 GPS 或可确认行程通过，也不等于用户已验收 0.2。

本轮动态展示验证中，冻结协议的三次方案展示与一次澄清展示均在最多一次完整反馈内有效；小批次不代表长期生成成功率。原生回归及 15 项新增结构／地图边界通过。正式同版实际服务联调使用显式模拟起点、真实 Maps 与高德取得 7 条不可行候选，复用该批次的真实 M3 布局，完成地图随切卡更新、展开／收起与地点／条件编辑，未新增模型调用或重置原截止。这是 UI 联调，不是新一轮完整自主规划或真实 GPS 验收。横排长按钮仍可能截断，完整内容与操作可滚动查看；当前证据与剩余验收归[动态界面任务包](tasks/agent-generated-ui/packet.md)。

这不是官方 Navigation 示例，而是从官方 My Notes 模板演进的应用。当前仅验证 macOS arm64。日历与笔记仍是明确标注的模拟来源，地图与模型使用在线服务；真实位置模式需要 macOS 系统授权及定位服务。尚未接通真实日历／笔记账户、导航执行、持续重规划或长期偏好学习。费用与耗时是供应商估计，推荐仅表示已核实候选中的最低估价，不保证实际到达或成交价。此前两次在线任务使用模拟位置，分别验证公共交通和混合候选，驾车费用均保持未知。混合费用直接使用供应商完整候选总价；综合耗时包含供应商等车估计，叫车等待未单独核实。未知价格、过期与端点等边界另经隔离原生检查。全程打车缺少候车数据时只作对照。时间与预算不设演示上限，仍检查数值能否精确表示及运算溢出。首轮支持数字分钟数与“预算”金额；无法识别的硬约束需要澄清，不能由模型自行放宽。

开发指引见 [AGENTS.md](AGENTS.md)，知识归属和当前任务见 [文档导航](docs/index.md)。仅采用 SVC 的文档知识层与 task packet；它们不是应用中的用户记忆能力。

## 开始开发

macOS Apple Silicon 是当前验证目标，需要 Git、Rust stable、Python 3.9+ 和可用图形会话。依赖源码放在仓库同级的忽略目录，不进入参赛包；首次编译需要网络与数 GB 磁盘空间。

在 Git 忽略的 `.env` 配置 `AMAP_API_KEY`、`MINIMAX_API_KEY`、`MINIMAX_BASE_URL` 和 `MINIMAX_MODEL=MiniMax-M3`。高德使用 Web 服务 Key，当前模型地址固定为 `https://api.minimax.cn/v1`。启动器生成隔离宿主 profile 和应用私有配置，权限为 0600；凭据不进入 `bundle/`、Git、模型输入或日志。受信任的本地应用在运行时读取高德与 M3 Key，具体边界见[架构说明](docs/architecture.md#宿主集成)。

```sh
cd ~/Development/agentic26
make agent-bootstrap   # 应用固定定位与 Maps 选点覆盖并构建 OctoSense desktop
make agent-doctor      # 检查版本、配置及打包边界，不请求在线服务
make agent-init-demo   # 重置独立模拟来源及时间；会关闭本启动器的实例
make agent-dev         # 显示应用窗口，规划时请求真实设备定位
```

`agent-init-demo` 将日历航班设为两小时后，并生成独立笔记与带当前时间的位置记录。默认位置为宝安大仟里室外步道的模拟坐标，曾在上述真实查询中返回可行混合候选；实时结果可能变化。三份模板在 `demo/`，运行数据在 `.local-state/agent/` 的应用 jail 中；普通启动保留已编辑的日历与笔记，默认位置来自系统。使用 `make agent-demo` 才读取模拟位置；该模式位置超过 15 分钟会阻止规划，需明确执行初始化命令。

```sh
make agent-status
make agent-tree
make agent-logs
make agent-shot SHOT=build/debug.png
make agent-stop
make agent-hidden      # 相同接口，隐藏窗口，用于原生交互验收
make agent-demo        # 显式模拟定位演示；不会在真实定位失败后自动切换
make smoke             # 隔离数据与离线合成响应的行为检查
make check             # 同一锁定 Hub 的包预检；不替代真实任务验收
```

正式启动器在隔离目录生成本地 `.app` 并直接运行包内宿主，保留系统定位用途声明；不修改系统权限。

真实位置需取得 100 米以内精度、60 秒以内的系统样本，最多等待 15 秒；拒绝权限、不可用或精度不足时显示错误。坐标经高德转换，并独立核实起终点城市及计价依据。城市信息、费用或有效路线缺失时明确失败，不填入深圳或模拟答案。确认时样本超过 60 秒须重新规划，不能仅刷新时间。位置将用于高德坐标／城市／交通请求，并作为 Agent 工具观察发送给 M3。

修改应用后重新执行 `agent-dev` 或 `agent-hidden`。官方系统应用在编译时嵌入，启动器会重新打包、增量编译，并核对实际挂载源码，不能靠重启旧二进制加载新脚本。启动器只关闭它自己管理的实例。调试接口、运行版本和目录说明见[工具链说明](toolchain/README.md)。

旧 `make bootstrap`、`make doctor`、`make dev` 与 `make run-hidden` 仍保留为 App Hub card-host 路径，适合不需要宿主模型服务的隔离实验；完整 Navigation 使用上面的 `agent-*` 命令。两条工具链分别由 `toolchain/sources.lock.json` 与 `toolchain/agent-runtime.lock.json` 锁定，不修改个人全局模型配置。实时定位、Maps 选点与字体附属文档校验的本地覆盖分别锁定并验证，不能将带补丁运行称为未修改的 stock 宿主。字体许可和复现说明中的普通来源链接不作为运行资源；实际嵌入资源仍按主机权限检查。Maps 往返需要本仓库的宿主扩展，不是官方版本已有的跨应用契约；应用包仍为 OctoScript。包预检使用相同权限定义的锁定 Hub CLI，旧 card-host 的权限闭名单保持原样。

真实截图必须来自当前应用并查看后再更新 `bundle/screenshots/01-main.png`。包编辑后执行 `make check` 更新摘要；签名后的包不能直接沿用此编辑流程。历史初始化证据见[验证记录](docs/verification.md)，当前行为的验收证据见[动态界面任务包](tasks/agent-generated-ui/packet.md)，0.2 联动见[交互任务包](tasks/interaction-integration/packet.md)，0.1 与此前在线基线见[能力任务包](tasks/capability-boundary/packet.md)。
