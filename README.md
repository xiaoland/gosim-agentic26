# agentic26 · Navigation

GOSIM Agentic App 2026 参赛开发仓库，主场景为 Navigation，实现方向为**帝王蟹能力层**。

## 产品目标

在限定时间内组合步行、公交、地铁和打车，以最低费用抵达目的地，包含混合路线中的打车计费。长期目标是通过已授权的跨应用上下文和偏好减少用户表达；当前阶段只做独立查询，不建立长期记忆或对话澄清。日历、消息、机票邮件或设备状态是候选数据源，具体接入尚待确定。

初赛以 OctoScript 应用交付，复用比赛官方宿主，应用模型指定为 MiniMax M3（`MiniMax-M3`）。Agent 通过工具读取背景、查询交通并决定下一步，确定性代码检查候选路线，应用呈现方案和任务结果。模型与交通循环复用现成网络接口；用户另行批准补齐 macOS 实时定位的宿主链路，参赛应用仍以 OctoScript 交付。本项目继续以可被调用的出行能力为重点，自然语言入口与可纠正的目的地、候选方案视图是当前开发入口。

直接服务接入已获用户允许，不再要求所有数据与操作经过手机既有应用。首轮先接任务必需的服务；天气、提醒、手机自动化和运行时动态生成工具不作为前置，避免扩展到完整出行服务平台。

当前路线规划不按演示城市限制起终点，输入是一句“40 分钟内到机场，预算 50，尽量便宜。”系统需要从已授权、有来源的行程、位置和偏好补全机场、币种和出发位置。没有可靠行程时，Agent 查询机场候选并提出可纠正的目的地假设；真实位置不能将模拟机票变成用户的真实行程。早期版本曾验证行程确认与恢复，但这些行为在当前无持久化方向中撤除；对应历史证据归[能力任务](tasks/capability-boundary/packet.md)。

演示背景也按实际来源分别提供：日历文件、笔记和设备位置记录。Agent 在运行时关联这些资料，形成带依据的出行约束；不预先把目的地、偏好和起点整理为一个“行程背景文件”。演示数据与真实在线服务结果分别标注。应用已接入一次性设备定位请求，默认使用真实设备位置，模拟位置保留为显式演示模式；系统调用的实际结果与完成证据见任务包。

后续考虑疲劳、最快等目标，比较时间、换乘和可靠性的候选方案。持续行程、交通变化时重规划和长期偏好学习均为后续方向，不属于当前独立查询。“最慢”的含义尚未确定；“最晚出发”是候选解释。

## 当前能力

0.8.0 按无持久化、无澄清的单次查询运行，并修复内容布局。每次点击查询建立新任务，位置、约束、来源、候选和 Agent 工具历史只服务本次运行；不保存或恢复行程，不把新输入当上一轮补充，也不通过问题澄清等待用户回答。未知信息应形成有依据的假设、具体缺失或查询失败结果，不能伪造机场、航站楼或价格。

业务和展示由同一个 MiniMax M3 Agent 自主编排。应用提供定位、地点、交通、确定性比较、按需技能和原生渲染工具；固定外壳仅输入框和查询／终止按钮，其余内容由 Agent 生成 Splash／Makepad。没有预制分区、组件树白名单、地图数量或人为输出限制。原生布局资料解释内容自然高度与文字换行，生成区承载手机视口中的滚动；不规定页面组织。

正常模式从宿主取得真实位置，日历和笔记账户尚未接入，不提供演示文件作为用户背景。显式 demo 模式保留分别提供的日历、笔记和位置来源，不能伪装成真实个人数据。地图与交通使用在线高德服务；确定性代码计算已查询候选的费用、耗时和未满足条件，费用未知不等于零，不可确认现实全局最优或实际到达保证。来源资料、运行配置和技能材料不是用户查询结果，不受行程保存机制管理。

本轮9项针对性原生检查通过，覆盖每次独立会话、旧结果文件不读不写、终止迟到响应、再次查询的新时间和预算、Android长文字换行及滚动到末行。真实live查询中定位超时，M3取得实际机场候选并根据执行诊断修正生成稿，未形成路线；随后复用这份真实稿在修复后布局确认末尾可达，不把它称为重新完成在线规划。真实稿仍含内部字段与过时“正在处理”标题；已补简短用户输出目标，但没有新增模型抽样证明内容质量已可靠。当前剩余局限、源码差异和完整证据归[动态界面任务包](tasks/agent-generated-ui/packet.md)，用户验收仍待进行。

0.7.0曾用模拟起点和真实服务完成自主查询与生成按钮交互，但存在文案误判和裁切；旧版本的Trip确认、读回与恢复记录只证明历史行为，当前不再提供这些入口。

Navigation 单独使用中文无衬线字体，其它应用文楷主题保持原样。当前验证目标为 macOS arm64 宿主 Android 手机模式，未验证 Android 真机。尚未接通真实日历／笔记账户、导航执行、持续监测或长期偏好学习。地图使用供应商同源几何，缺段不补造直线；历史 Maps 选点往返使用锁定的宿主扩展，本轮单次查询不提供该交互，也不申请 maps 能力。

开发指引见 [AGENTS.md](AGENTS.md)，知识归属见 [文档导航](docs/index.md)。仅采用 SVC 的文档知识层与 task packet，它们不是应用记忆能力。

## 开始开发

macOS Apple Silicon 是当前验证目标，需要 Git、Rust stable、Python 3.9+ 和可用图形会话。依赖源码放在仓库同级的忽略目录，不进入参赛包；首次编译需要网络与数 GB 磁盘空间。

在 Git 忽略的 `.env` 配置 `AMAP_API_KEY`、`MINIMAX_API_KEY`、`MINIMAX_BASE_URL` 和 `MINIMAX_MODEL=MiniMax-M3`。高德使用 Web 服务 Key，当前模型地址固定为 `https://api.minimax.cn/v1`。启动器生成隔离宿主 profile 和应用私有配置，权限为 0600；凭据不进入 `bundle/`、Git、模型输入或日志。受信任的本地应用在运行时读取高德与 M3 Key，具体边界见[架构说明](docs/architecture.md#运行材料与开发记录)。

```sh
cd ~/Development/agentic26
make agent-bootstrap   # 应用固定定位与 Maps 选点覆盖并构建 OctoSense desktop
make agent-doctor      # 检查版本、配置及打包边界，不请求在线服务
make agent-init-demo   # 重置独立模拟来源及时间；会关闭本启动器的实例
make agent-dev         # 显示应用窗口，规划时请求真实设备定位
```

`agent-init-demo` 将日历航班设为两小时后，并生成独立笔记与带当前时间的位置记录。默认位置为宝安大仟里室外步道的模拟坐标，曾在上述真实查询中返回可行混合候选；实时结果可能变化。三份模板在 `demo/`，运行数据在 `.local-state/agent/` 的应用 jail 中；普通启动保留已编辑的日历与笔记，但正常模式不将它们作为任务来源；默认位置来自系统。使用 `make agent-demo` 才读取模拟位置；该模式位置超过 15 分钟会阻止规划，需明确执行初始化命令。

```sh
make agent-status
make agent-tree
make agent-logs
make agent-shot SHOT=build/debug.png
make agent-stop
make agent-hidden      # 相同接口，隐藏窗口，用于原生交互验收
make agent-demo        # 显式模拟定位演示；不会在真实定位失败后自动切换
make smoke             # 隔离数据与离线合成响应的行为检查
make check             # 同一锁定 Hub 的包预检；不替代真实任务验收
```

正式启动器在隔离目录生成本地 `.app` 并直接运行包内宿主，保留系统定位用途声明；不修改系统权限。

真实位置需取得 100 米以内精度、60 秒以内的系统样本，最多等待 15 秒；拒绝权限、不可用或精度不足时显示错误。坐标经高德转换，并独立核实起终点城市及计价依据。城市信息、费用或有效路线缺失时明确失败，不填入深圳或模拟答案。当前查询使用定位样本的真实采样时间，不能仅刷新时间伪造新位置。位置将用于高德坐标／城市／交通请求，并作为 Agent 工具观察发送给 M3。

修改应用后重新执行 `agent-dev` 或 `agent-hidden`。官方系统应用在编译时嵌入，启动器会重新打包、增量编译，并核对实际挂载源码，不能靠重启旧二进制加载新脚本。启动器只关闭它自己管理的实例。调试接口、运行版本和目录说明见[工具链说明](toolchain/README.md)。

旧 `make bootstrap`、`make doctor`、`make dev` 与 `make run-hidden` 仍保留为 App Hub card-host 路径，适合不需要宿主模型服务的隔离实验；完整 Navigation 使用上面的 `agent-*` 命令。两条工具链分别由 `toolchain/sources.lock.json` 与 `toolchain/agent-runtime.lock.json` 锁定，不修改个人全局模型配置。实时定位、Maps 选点、字体附属文档校验与低层控件寻址／尺寸的本地覆盖分别锁定，不能将带补丁运行称为未修改的 stock 宿主。字体许可和复现说明中的普通来源链接不作为运行资源；实际嵌入资源仍按主机权限检查。Maps 往返需要本仓库的宿主扩展，不是官方版本已有的跨应用契约；应用包仍为 OctoScript。包预检使用相同权限定义的锁定 Hub CLI，旧 card-host 的权限闭名单保持原样。

真实截图必须来自当前应用并查看后再更新 `bundle/screenshots/01-main.png`。包编辑后执行 `make check` 更新摘要；签名后的包不能直接沿用此编辑流程。历史初始化证据见[验证记录](docs/verification.md)，当前行为的验收证据见[动态界面任务包](tasks/agent-generated-ui/packet.md)，0.2 联动见[交互任务包](tasks/interaction-integration/packet.md)，0.1 与此前在线基线见[能力任务包](tasks/capability-boundary/packet.md)。
