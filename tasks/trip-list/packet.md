# 持久化出行列表与详情主页

状态：2026-10-11，0.16.0 实现与交互验证完成。基线 main 9b3c291（0.15.0）。

## 目标、授权与交付

用户要求：“提供一个‘出行列表’，之前我们一直没做持久化，现在是时候做了；出行列表应该放在sidebar中，index page即出行详情页面”。沿用自主提交推送、真实 M3 验证及临时定位授权。

已实现应用内左侧出行抽屉，主页显示选中出行详情。新建草稿、提交普通查询即可建立记录，不需要确认守护目标；可切换和删除出行。确认目标、费用、结束及核验均归当前出行。旧单目标迁移保留原期限和预算，新库建立后不再双写或重复导入。

本轮替换此前仅保存单个确认目标的边界：持久化成功生成的原始 DSL、历史事实及路线几何，恢复卡片、详情和地图；不恢复模型消息、未确认提案、VM 或继续运行。冷启动和选择只读展示，原来的启动自动核验取消，用户主动重新规划或核验。历史时间可见，旧报价和交通依据不伪称当前有效。切换失效旧回调与生成实例。

轻量索引加各条独立 revision 保存完整详情，避免所有出行积累到宿主单文件1MiB限制；更新先写详情后切索引，保留备份，失败不推进内存。删除提交时备份也排除所删记录，成功后清理无引用详情。长期行为已回流 README、docs/architecture.md、toolchain/README.md。

root 负责整合、文档和提交；guardian_design 负责生命周期/存储/恢复判断；guardian_impl 负责 bundle 和必要宿主窄补丁；guardian_verify 负责 tools 回归和实际证据。全部测试实例已关闭，无待用户决定事项。

## 已解决的实际失败与剩余边界

首次整稿恢复条件只看blocks数组，导致source整页被跳过，已修。宿主ScriptVM增量加载用旧字节长度截取新源码，落入中文字符中间会在解析前panic；现有锁定补丁已用安全prefix读取，非法字符边界按全文变化重新解析，不改写Agent稿。相同中文滚动稿实际重开已验证。

真实在线结果初次保存/重启成功，但侧栏切换因重复深复制全列表几何和DSL超过宿主执行预算，出现索引已保存而UI未切换。现以独立记录头和只读快照共享、跳过已保存终态重复捕获解决；同份真实数据四次切换与重启补证，不提高预算或截断详情。

每个出行文件仍受宿主1MiB及应用总额度限制，超限明确保存失败，旧记录保留。没有后台监控、自动订单、Android真机或新演示视频。生成界面的完整性仍取决于模型；本轮保证保存/恢复已成功生成的内容，不补静态路线模板。旧守护测试的软键盘遮挡属于驱动修正，未据此增加产品分支。
