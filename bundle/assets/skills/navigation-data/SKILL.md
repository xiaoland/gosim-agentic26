# 地点与路线事实

read_location按配置读取明确模拟位置，或通过已授权前台location.sample取得设备位置并核实城市；工具不自动弹定位授权。真实read_calendar仅读用户已选日历，可选择Unix毫秒时间窗及1..200的limit，返回原始事件与truncated。真实read_notes(query)搜索官方Notes摘要，read_note(id)按真实搜索ID取得原文；未授权、应用未运行、空结果如实返回。日历与笔记是独立来源，不要求两者同时存在，不证明机票已购买。demo仍有独立模拟read_calendar/read_notes/set_constraints；后者保留记录ID和逐字citations合同。用户时间与预算不变，金额单位为整数分。search_places返回全部真实POI选择资料与node_ref，入口对象由get_route_graph(node_refs)按需读取；adopt_destination采用已有poi_id，返回目的地、披露入口范围、constraints和原绝对期限，保留明确选择或来源推断依据。

地点中心poi:<id>不等于入口。有效高德entr_location作为独立entrance:<id>返回并保留来源、设施身份与查询时间；不用exit_location替代入口。明确机场T编号航站楼被采用后，destination.routing_point披露默认路由入口，canonical POI中心不改；具体门、用户坐标、无入口设施不替换。query/extend与实际端点核验共用该绑定，destination_access说明仅到供应商标注入口，内部通达、楼层和安检未知；endpoint_complete仅证明到所绑定点，不认证进入大厅或赶上航班。费用仍为已查段小计，不填内部连接时间或费用。历史记录沿当时保存的点，不自动改成后来发现的入口。

query_route从本次起点查询，省略to_ref到最终目的地，指定真实中转node_ref则只建立到该节点的新前缀；transit策略由参数说明，taxi为高德单路径驾车估价，候车未知。extend_route从origin或本轮Route实际末端到真实node_ref查询本次供应商区间，返回新Route，原Route不变。Route id用于读取、比较、提案与查看，geometry_ref用于真实地图几何；模型不传polyline或手算重建路线。

一个leg是一笔完整供应商查询，公交内部steps不是独立收费边，不能按站数/距离拆票价或替换其内部taxi step价格。query_route回执保留Route摘要与new_nodes，success只表示查询完成，不保证目标可行；new_nodes保留节点引用与来源，坐标由get_route_graph(node_refs)按需读取。完整legs与详细segments由get_route(id)读取，segments保留真实分段duration/distance、walking/taxi及每条busline的line_id、上下站node_ref与有序stops；不再重复顶层steps。只有steps的旧历史保留原表示。供应商缺失字段为nil。get_route按线路分别提供有序stops及route内leg/segment关系；get_route_graph默认提供全部节点/Route精简索引及完整有序线路关系，不重复完整Route详情或节点来源材料；同站属于多条候选的关系不会覆盖。需要某个节点的完整来源、坐标依据、入口及全部memberships时，用同工具node_refs:[ref,...]按需读取；只返回指定节点及其关联，missing_refs明确本轮不存在的引用。完整Route仍用get_route(id)。替代buslines各有自己的站序，不把它们拼成一条线路。stop缺有效ID/坐标时node_ref仍为nil。

cost.amount_cents与full_journey_amount_cents均为请求全程估价，complete只说明全程金额已具备；全程覆盖或连接未知时二者为nil、complete=false。queried_legs_amount_cents是所包含legs报价合计，queried_legs_complete说明每个供应商查询leg的报价字段可解析且齐备，不证明其内部各交通step票价包含关系已核实；known_subtotal_cents仅已知小计，不能当全程金额。Route的price_cents别名同样仅表示全程价。coverage=queried_legs_only的小计不是到目的地总价；unknown不是零。费用为整数分且保留currency、basis与来源。供应商option／leg的报价不等于请求全程覆盖；budget_status或deadline_status为unknown时不能由小计扣出“剩余预算”，或由已查终点时刻宣称满足目的地期限。

completion_status区分reached_requested_destination/incomplete/unknown，实际末端不等于请求坐标。代码检查实际端点连接并累计时间；公交按前序最早抵达场景查询，前序未知候车可能改变班次。未来打车仍使用查询当时交通估计。get_route提供estimated_arrival_ts与waiting_slack_seconds，余量不是已知候车时间。

duration_seconds保留已查场景的数值，duration_scope说明它只到已查终点或请求路由点；duration_label已包含范围，duration_basis说明供应商或固定班次的最早场景。不能将局部“约164分钟”当作门到门耗时。get_route的waiting_slack_seconds只在请求路由点有到达估计时提供，仍是最早场景的期限余量，不是已知候车时间或准时保证；queried_endpoint_slack_seconds只到已查终点。query回执的queried_to_ref是本次查询目标，leg_to_ref是实际登记末节点，overall_destination_ref／requested_destination_ref表示整体目标，三者不能混同。

新规划期限从received_at起算，查询和生成时间计入；守护使用已确认绝对期限。assessment由当前时刻重算：预算、截止、连接、候车和时效各自判断。passed=false不等于每项超限；数值在范围内不能认证未知连接/候车。来源expires_at与到达截止不同。get_route/get_route_graph/compare_routes只读已有资料，不重新查询供应商；已查范围不证明全局最优。compare_routes返回全部候选的身份、模式、完成／到达范围、price_label／duration_label／arrival_label和当前assessment；cost包含整程amount_cents、已知小计、币种、覆盖与未知原因。完整端点、时刻、计价依据、分段、步骤、来源和地图元数据由get_route(id)读取，同一Route身份不变。

滴滴配置事实只表示Key是否配置，不等于服务可用。search_didi_places返回供应商地点ref，quote_didi只用该ref询价；price_text与price_cents采用供应商当前可用优惠报价；缺优惠时采用普通报价。base_price_text／base_price_cents保留普通原价对照，discounted_price_text保留优惠原文。存在但无法精确解析的优惠金额为nil，不能以普通价冒充有效价。attach_quote只替换明确taxi leg的当前报价并返回新Route，不与原价叠加。place_basis保留两端名称、城市、地址及入口对应依据；供应商坐标系未声明，不能冒充高德端点。派生保留原耗时/几何/完成状态，不认证上下车连接；当前价不保证未来接驳价格。

探索策略见mixed-routing；已确认目标规则见journey-guardian；呈现、事件和地图接口见native-ui。普通结果保存为带时间的历史资料，不恢复模型会话，也不自动续跑。

工具回执含completion_status=incomplete及published_route_ids时，所列仅为本调用已完整登记的Route；未完成方案不能引用或手算补成完整行程。局部节点可能已经登记，不代表方案完成。可读取保留的Route并自行决定下一工具，不自动重试。

铁路service的departure_label、arrival_label为固定班次的北京时间发到标签，duration_label仅为列车区间耗时。方案费用、实际覆盖范围的耗时和到达范围使用同一Route的price_label、duration_label、arrival_label；estimated_arrival_ts/label仅在端点核实到请求路由点时提供，官方入口仍不证明设施内部通达。queried_endpoint_arrival_ts/label保留已查路段终点估计，arrival_scope=queried_endpoint_only时不能称到达最终目的地；等待固定班次可能跨夜，不能用列车区间耗时替代整程。

费用的queried_legs_amount_cents／queried_legs_complete分别保留已查区间报价合计与各供应商leg报价字段的齐备状态，queried_legs_scope、queried_leg_count和unknown_reasons解释覆盖终点及未核接入；即使全部已查腿有价，到官方入口的估价仍可能遗漏未核连接附加费用。destination_access说明内部通达未知，不表示一定收费。可以推荐条件成立／unknown方案，但不能把它称为已满足预算或期限；不要将别条Route或未选班次的票价拼入旧Route来认证总价。新提案风险文字不是用户已接受，不能覆盖原用户risk_acceptance。

高德单个option／leg是供应商本次查询区间报价；各交通分段票价及包含关系未知，无法据此确认是否包含城际车票。不同铁路站对的价格可以保留其站对与适用假设，作为待核验预算参考，不能叠到本Route认证整程价；预留预算不称票价上界。
