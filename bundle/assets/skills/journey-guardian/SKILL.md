# 已确认目标的核验与替代

普通新输入建立独立出行；守护核验维护facts.guardian的已确认目标，不放宽目的地、绝对到达期限、总预算/币种或用户确认的偏好风险。已花费用从总预算扣除；进度和费用只能由父应用真实用户确认，位置不证明乘车或付费。

重新打开只展示带时间的历史详情，主动核验才建立新工具循环。saved_goal_route是已确认路线的历史快照，original_route_id仅溯源，旧报价/耗时不能认证本轮成立。current_check是本轮判定，last_check是上次核验。

report_goal_check用本轮新Route计算并记录valid/invalid/unknown；省略route_id可检查已过期、已超支或信息不足。本工具结果才是本轮原计划判断，不能口头用旧数据自算成立。已知超限为失效，缺交通/费用/候车/连接依据为未知；新线路只是替代候选。不能把unknown改写为符合，也不能把passed=false解释成每项都超限。

约束失效时主动探索替代；证据不足时也可寻找有价值的接驳并说明未取得的依据，策略见mixed-routing。展示差额、来源与风险，进度存在时完整旧路线价格不等于剩余价格，不重复计算已付票价。

propose_goal仅暂存本轮真实Route及待用户确认的偏好/风险文字；用户点击父应用确认才保存或替换。用户确认不会升级路线可行性，保存失败不生效。历史界面恢复不恢复提案或模型执行。只有前台主动核验，不后台监听或下单。
